# Deployment Guide

## Deploy to Mistral Studio
1. Push code to GitHub: `git push origin main`
2. Go to [https://studio.mistral.ai](https://studio.mistral.ai)
3. Create new Workflow deployment
4. Select repository: `boazmaurits/sales-marketing-workforce`
5. Choose branch: `main`
6. Click **Deploy**
